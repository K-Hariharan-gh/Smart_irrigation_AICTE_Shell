# Smart_irrigation_AICTE_Shell
This is a internship project provided by AICTE and Shell

__Project Name:Smart/Automate Irrigation using Soil Moisture and Weather Data:__ \
In this project, I learned how to train an AI model and deploy it. The model was trained to analyze changes in the soil and predict the appropriate sprinkler status. This approach allows irrigation to be carried out more efficiently. The goal is to uncover valuable data hidden within the soil, which can help adapt irrigation strategies for different soil types without requiring human interaction.

__Benefits and Positive Impacts:__\
__-->__ We could save "The Essence of human life", that is water in a large amount.\
__-->__ Human intervention is heavily reduced.\
__-->__ Irrigation can be performed even in a distant/remote locations such as mountain peaks.\
__-->__ This project will help us to perform irrigation on harsh terrains.\
